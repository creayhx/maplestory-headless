# 怪物基础结构

CMS 79 中怪物对象系统的基础数据结构汇总。涵盖 CMobPool（怪物池）、CMob（怪物对象）、CRC保护系统、全局变量和函数总览。

---

## 1. 怪物池 CMobPool

### 全局指针

```
[0x00BDD49C] → CMobPool*
```

### 结构

```
CMobPool (this = [0xBDD49C])
  ├─ +0x00: vtable       (0x00B04FE0)
  ├─ +0x04: 列表哨兵     (ZList sentinel)
  ├─ +0x0C: 怪物数量     (int, 当前地图怪物总数)
  ├─ +0x28: 怪物槽指针   (ZArray 第一个槽)
  ├─ +0x5C: 当前交互目标/玩家控制的实体指针（AI目标选择用）
  ├─ +0x60: 相关对象引用
  ├─ +0x68: 当前活跃处理中的怪物指针
  └─ +0x6C: 上次攻击检测时间戳
```

## 2. 枚举怪物（ZArray 遍历）

### ZArray 遍历算法

```
slot = *[pool + 0x28]        // 第一个槽指针
while slot != NULL:
    mobPtr = *[slot + 4]     // CMob* 指针
    if mobPtr != NULL:
        // 处理怪物 ...
    
    v12 = *[slot - 12]       // 下一个槽偏移
    slot = (v12 != 0) ? v12 + 16 : NULL
```

### CE Lua 枚举脚本

```lua
local poolPtr = readInteger(0x00BDD49C)
local firstSlot = readInteger(poolPtr + 0x28)
local slot = firstSlot

while slot and slot > 0x10000 do
    local mobPtr = readInteger(slot + 4)
    if mobPtr and mobPtr > 0x10000 then
        local vtable = readInteger(mobPtr)
        local mobIdEnc = readInteger(mobPtr + 0x124)
        local mobIdCrc = readInteger(mobPtr + 0x12C)
        -- 处理 ...
    end
    
    local v12 = readInteger(slot - 12)
    if v12 and v12 ~= 0 then
        slot = v12 + 16
    else
        break
    end
end
```

## 5. CRC 完整性保护系统

### 核心函数

| 函数 | 地址 | 功能 |
|------|------|------|
| `ZtlSecureFuse_long_` | 0x416DE8 | CRC校验读取：解码并验证内存值完整性 |
| `ZtlSecureTear_long_` | 0x416E36 | CRC编码写入：生成随机key并计算校验码 |

### ZtlSecureFuse_long_ 实现

```c
int __cdecl ZtlSecureFuse_long_(int *a1, int a2)
{
    // a1[0] = 受保护的值(密文), a1[1] = key
    // a2 = 期望的checksum
    
    int decoded = a1[0] ^ sub_A705FB(a1[1], 5);  // XOR解密
    
    // 校验: key + ROR4(密文 ^ 0xBAADF00D, 5) == checksum
    if (a1[1] + _ROR4_(a1[0] ^ 0xBAADF00D, 5) != a2)
        throw C++异常(5);  // 内存被篡改!
    
    return decoded;  // 返回真实值
}
```

### ZtlSecureTear_long_ 实现

```c
unsigned int __fastcall ZtlSecureTear_long_(int value, int *output)
{
    int key = CRand32::Random(g_rand_0);  // 随机key
    
    output[0] = key;
    output[1] = _ROR4_(value ^ key, 5);
    
    return output[1] + _ROR4_(key ^ 0xBAADF00D, 5);  // 返回checksum
}
```

### CRC保护的字段

| 怪物对象偏移 | 校验位置 | 含义 |
|-------------|---------|------|
| `mob+0x130` | `mob+0x138` | 移动解码器状态（期望值=1） |
| `mob+0x394` | `mob+0x39C` | 移动动作计数器 |
| `mob+0x3A0` | `mob+0x3A8` | 移动状态值 / **死亡计时器** |
| `mob+0x3AC` | `mob+0x3B4` | 移动路径相关 |
| `mob+0x3B8` | `mob+0x3C0` | 移动路径相关 |
| `*(mob+0x178)+0x40` | `*(mob+0x178)+0x48` | CPhysical子对象位置值 |

**CRC保护的是移动解码器的状态机**（"当前是否在移动"、"动作序号"等），**而不是坐标值本身**。怪物 X/Y 坐标（mob+0x4C4~+0x4D0）**无CRC保护**。

### 密钥变更流程

```c
void CMobPool::OnMobCrcKeyChanged(int a1@<ebp>, int a2)
{
    // 1. 从数据包读取新的CRC密钥
    this->crc_key = CInpacket::Decode4(packet);
    
    // 2. 标记所有怪物需要重新编码
    for (mob_node = this->mob_list; mob_node; mob_node = mob_node->next)
        mob_node->mob->crc_dirty_flag = 1;
    
    // 3. 发送ack回服务端(opcode 0xA0)
    COutPacket::COutPacket_2(a1, 160);
    CClientSocket::SendPacket(a1 - 28);
}
```
