# analysis — 客户端机制逆向笔记

> 对 **MapleStory CMS 079 客户端**（`MapleStory.exe`，脱壳版，`ImageBase = 0x00400000`，**无 ASLR**）
> 的内存级考证笔记，共 24 篇。

## 这批文档是什么

- **是**：客户端侧的机制考证 —— 数据结构布局、函数地址、调用链、Hook 点、patch 字节。
- **不是**：本项目的协议实现。bot 走网络协议驱动角色，**不读客户端内存、不注入进程**，
  实现全在 `src/`；这里只是"客户端是怎么做的"的对照参考。
- **地址约定**：基址 `0x00400000` 且无 ASLR，所以文档里的**绝对地址 = RVA + 0x400000**，
  可以直接对照。写成 `MapleStory.exe+10D7A6` 的则是 RVA 形式。

因为无 ASLR，这些地址在同一版本的客户端上是稳定可复现的；换客户端版本则全部作废。

## CT 表 — `MapleStory079.CT`

这批笔记的**可操作产物**。笔记负责讲清原理，CT 表负责复现 ——
把散落在各篇里的地址与字节组织成「勾选即生效」的条目。

规模：**251 个条目 / 15 个分组 / 36 段注入脚本 / 196 条地址记录**
（`CheatEngineTableVersion 46`）。

| 分组 | 作用 |
|---|---|
| **基址** | 一切条目的指针源头：模块基址，以及人物 / 坐标 / 人物数量 / 地图 / 怪物数量 / 物品数量 / 鼠标状态 / 血量 / 输入框 / 目录菜单 等全局指针 |
| **地图** | 地图 ID、四壁（上/下/左/右）、地图移速、击退距离、重力、跳跃高度、飞行速度 |
| **人物** | 朝向、状态、XY 坐标缓存、移动处理坐标、移动位置生效；以及「停止呼吸」「攻击无延迟」「攻击加速」「攻击不停」等行为 patch |
| **怪物** | 场景怪物计数 |
| **物品** | 物品计数、物品速显 |
| **拉怪 / 吸怪 / 怪物变笨** | 三类怪物行为干预（对应 `怪物跟随.md` / `怪物AI与仇恨.md`） |
| **BUFF** | 攻击力 / 物防 / 魔法力 / 魔防 / 命中 / 闪避 / 移速 / 跳跃力 / 快速武器 / 冒险岛勇士 / 稳如泰山 / 火眼晶晶 —— 即 `BUFF加密机制.md` 的「地址 ↔ 表名」对照表 |
| **BUFF-属性** | 加密块本体（`子对象+0x14 / +0x24 / +0x2C …`），改写走 `BUFF物防-修改值生成` 一类脚本 |
| **技能特效** | 屏蔽特效：`禁用人物自身技能特效`（ID 328，2 个 patch）、`禁用怪物受击特效`（ID 331，6 个 patch） |
| **放置物全图攻击** | Reactor 全图打击（对应 `放置物详解.md`） |
| **背包查询-只能同时开启一个** | 背包遍历。**互斥** —— 同时开多个会互相干扰 |
| **分辨率相关** | UI 控件坐标与尺寸常量（对应 `游戏UI尺寸.md`） |

**用法**：属性类条目直接改值；patch 类条目是脚本，注入即生效，其中一部分要先靠
`基址` 分组解析出指针。

> 地址依赖「无 ASLR + 该客户端版本」，**版本不符时全部作废**。
